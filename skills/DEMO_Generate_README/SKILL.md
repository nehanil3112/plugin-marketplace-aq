# Generate README

**Category**: Demo

## Prompt

```
Generate a README.md for the current project. Include these sections:
- Project name and one-line description
- Installation steps
- Usage example
- Configuration (if any)
- License

Infer the content from the project files. Do not invent features that are not in the code.
```

## Usage

This prompt is ready to use. Simply:
1. Copy the prompt text above
2. Run it from the project root so the assistant can read package files
3. Review and edit the generated README

**Code Companion**: github-copilot, gemini, amazon-q
