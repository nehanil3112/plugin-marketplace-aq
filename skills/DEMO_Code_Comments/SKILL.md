# Add Code Comments

**Category**: Demo

## Prompt

```
Add explanatory comments to the selected code. Rules:
- Comment only the WHY, not the WHAT
- Skip lines whose intent is already obvious from the names
- Use the comment syntax that matches the file's language
- Do not change any executable code

Return only the modified code block.
```

## Usage

This prompt is ready to use. Simply:
1. Select the code you want commented in your editor
2. Copy the prompt text above
3. Execute it with the selection in context

**Code Companion**: github-copilot, gemini, amazon-q
